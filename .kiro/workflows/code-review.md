# 代码审查工作流

## 概述

ZeroTier SDK 代码审查的标准流程。

## 审查清单

### 代码风格

- [ ] gofmt 格式化
- [ ] 命名规范
- [ ] 中文注释

### 功能实现

- [ ] 逻辑正确
- [ ] 边界处理
- [ ] 错误处理

### API 设计

- [ ] 接口一致性
- [ ] Builder 模式
- [ ] Option 模式

### 测试

- [ ] 单元测试
- [ ] 覆盖率
- [ ] 边界测试

### 文档

- [ ] 代码注释
- [ ] README 更新
- [ ] 示例代码

## 审查命令

```bash
# 代码检查
make lint

# 运行测试
make test

# 构建验证
make build
```

## 反馈格式

```markdown
## 审查结果: [通过/需修改]

### 问题

1. [文件:行号] 问题描述
   建议: 修改建议

### 建议

- 改进建议
```
